### Passo a passo para rodar o projeto localmente

## Clone o repositório pelo terminal
*Garanta que você tenha git instalador em sua máquina*

bash
`
git clone https://github.com/lucassantin/Catmop/
`

## Rodar o projeto
*Garanta que você tenha o NodeJs instalado em sua máquina*

bash
`
npm install
`

em seguida:

bash
`
npm run dev
`
Feito isto, acesse no seu navegador o seguinte endereço para acessar a respectiva página
`
https://localhost:8080
`
